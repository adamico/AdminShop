# AdminShop 1.21.1 reference sources

The Java sources and resources of AdminShop 2.3.2 for Minecraft 1.21.1, moved here unchanged from
`src/main` when the `26.1.2/2.x` branch started. Gradle neither compiles nor packages this folder.

Each port ticket moves the feature it ports from here into `src/main`, rewritten for 26.1.2, and
deletes what it moved. The folder is gone once the port is complete.
